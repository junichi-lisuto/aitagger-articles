# aitagger-tools-site

**AIタッガー利用者向け「AI検索を知る」記事メディアのデータ管理リポジトリ。**

表示は Unbounce（LISUTO契約済み）が担う。このリポジトリは記事データの管理に専念する。

```
articles/    公開済み記事のHTML本文（1記事1ファイル）
automation/  記事の収集・承認フロー（Slack連携スクリプト）
mockups/     記事関連の下書き・プレビューHTML
index.html   記事一覧の簡易ビュー（Unbounce連携までの参照用）
```

作業のルールは `CLAUDE.md` に書いてある。

## 現在の状態（2026-09-16）

- ツール一式（旧`tools/`11本）とツール用モックアップは削除済み（矢頭の判断、復元予定なし）
- 記事5本を公開中（`articles/`）
- Unbounceとの連携は未着手。準備手順はチャットで確認しながら進める

## なぜツールを扱わなくなったか

以前は「ツール」と「記事」を同居させた公開サイトとして設計していたが、
表示をUnbounceに一本化する方針に転換した（2026-09-16）。
矢頭が今後触るのは記事のみのため、実装済みツールは削除した。
